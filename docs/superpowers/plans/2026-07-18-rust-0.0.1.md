# TUT 0.0.1 Rust Implementation Plan

**Status:** Implementation complete; source-coordinate foundation extended

**Goal:** Deliver one reliable local UTF-8 terminal reader for macOS and Linux.

## Product boundary

TUT 0.0.1 reads one local regular file into immutable validated storage, wraps it using terminal cell width, supports navigation and literal search, and restores terminal state on every recoverable exit.

The release has no network access, stdin document input, persistence, configuration, plugins, background work, or format abstraction.

## Engineering rules

- Keep one Cargo package until a second independently useful package exists.
- Keep terminal dependencies out of domain modules.
- Use absolute `u64` source-byte offsets as persistent identity.
- Share one grapheme projection between wrapping and rendering.
- Make large derived allocations fallible.
- Mutate the terminal only after command, TTY, file, and application validation.
- Record the first external signal and restore every marked terminal step in reverse order.
- Follow GNU command-line and Makefile conventions without claiming to be a GNU package.
- Keep source, tests, diagnostics, and documentation in English.
- Add comments only for non-obvious invariants or safety requirements.

## Implemented increments

### 1. Repository and build surface

- [x] Remove the obsolete C++/CMake/browser implementation.
- [x] Create the Rust 2024 package with Rust 1.88.0 as MSRV.
- [x] Commit a lockfile and pin the development toolchain.
- [x] Add standard GNU Make targets with `prefix`, `bindir`, and `DESTDIR`.

### 2. Command and document boundary

- [x] Parse `--help`, `--version`, `--`, and exactly one path from `OsString`.
- [x] Emit GNU-style help, version, diagnostics, and exit status.
- [x] Validate stdin and stdout terminals before file access.
- [x] Open nonblocking, validate the opened handle, and read at most 32 MiB plus one byte.
- [x] Validate UTF-8, logically exclude one leading BOM, and retain raw line endings.

### 3. Layout and search

- [x] Project extended grapheme clusters with one narrow-width policy.
- [x] Replace terminal controls and unsafe zero-width display atoms.
- [x] Build a compact greedy visual-row start index.
- [x] Preserve an absolute source-byte viewport anchor across reflow.
- [x] Build a one-bit-per-source-byte non-overlapping literal-search index.

### 4. Application and rendering

- [x] Implement navigation, progress, tiny-terminal behavior, and end following.
- [x] Implement transactional search editing with a 4096-byte draft limit.
- [x] Produce immutable visible render state with match highlighting.
- [x] Write projected atoms directly to Ratatui cells with frozen widths.
- [x] Render fixed header, body, status, and help regions.

### 5. Terminal lifecycle

- [x] Install retained first-signal handlers before file loading.
- [x] Use a synchronous event loop with bounded polling.
- [x] Mark cleanup before each terminal mutation.
- [x] Restore cursor, alternate screen, and raw mode in reverse order.
- [x] Retain both primary and restoration errors.

### 6. Verification and documentation

- [x] Add loader, layout, search, application, input, renderer, and lifecycle unit tests.
- [x] Add black-box command process tests.
- [x] Add bounded real-PTY restoration and signal tests.
- [x] Verify Rust 1.88.0.
- [x] Add README, architecture documentation, and pinned Linux/macOS CI.
- [x] Complete the final filesystem, language, dependency, formatting, Makefile, and release-build audit.

### 7. Mature-reader foundation

- [x] Introduce `SourceOffset(u64)` as the shared layout, search, and application coordinate.
- [x] Add a closed `DocumentStore` boundary with an in-memory backend.
- [x] Preserve original BOM displacement and LF, CRLF, or lone CR byte ranges.
- [x] Test layout and search with virtual source bases above `u32::MAX`.
- [x] Document the bounded-paging and background-work roadmap.

## Acceptance

Run from the repository root:

```sh
cargo fmt --all -- --check
cargo clippy --all-targets --all-features --locked -- -D warnings
cargo test --all-targets --all-features --locked
cargo +1.88.0 test --all-targets --locked
make
make check
```

Stage-install acceptance uses a fresh temporary directory and must prove that `install`, `installcheck`, and `uninstall` affect only `DESTDIR`.
